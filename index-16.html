Manual Operativo para el Docente

Guía pedagógica integral para utilizar el Asesor Psicopedagógico en el aula y en evaluaciones de alto impacto.

1 Configuración de la API Key de Google AI Studio

Haga clic en el botón superior derecho "Configurar API Key" e ingrese su clave gratuita de Google AI Studio. La clave se almacena exclusivamente en el almacenamiento local seguro de su navegador (localStorage) y nunca viaja a servidores intermedios.

2 Evaluador Clínico: Caso Individual vs. Grupo / Aula Completa

Utilice el selector de alcance para diagnosticar tanto a un estudiante individual (analizando su nivel de descarga cognitiva y contención afectiva) como a un grupo completo (detectando homogeneización masiva, colapso de debates y dinámicas colectivas de pérdida de soberanía).

3 Carga Multiformato de Evidencias (+)

Tanto en el Evaluador como en el Consultor en Vivo, puede presionar el botón de clip o (+) para adjuntar PDFs, documentos Word (.docx), tablas Excel (.xlsx/.csv), fotos de exámenes manuscritos o código. El sistema procesa los contenidos y los integra en el análisis diagnóstico.

4 Flujo Bidireccional de Consultoría

Al generar un diagnóstico, presione el botón 💬 Continuar y Profundizar en el Consultor en Vivo. El caso se transferirá automáticamente al chat, permitiéndole solicitar rúbricas analíticas, exámenes orales de 5 minutos o adaptaciones pedagógicas personalizadas.

5 Glosario Bilingüe y Marco de Fricción Metacognitiva

El sistema traduce y define al español cualquier término técnico (Cognitive Outsourcing, Sovereignty Trap, Epistemic Debt, etc.) y fundamenta cada estrategia en los 28 papers de Consensus, garantizando rigor científico y calidez humana.

Guía Rápida de Solución:
  • Error 429 (limit: 0 para un modelo): Su proyecto de Google Cloud tiene cuota cero asignada para ese endpoint o la cuota libre expiró. Se sugiere generar una nueva API Key en aistudio.google.com en un proyecto limpio sin restricciones.
  • Error de Red / CORS (Failed to fetch): Al ejecutar desde el sistema de archivos local (file://), el navegador móvil puede bloquear la llamada directa a la API por políticas de origen cruzado. Ejecute la app mediante un servidor local (http://localhost) o hosting web.
  • Error 400 / 403: Clave de API malformada o no habilitada en su región. Pulse "Cambiar API Key" para reconfigurarla.
